## Implementation Rules

1. **Test Name = AC**
   - Test name should describe the AC being tested
   - Example: `testAnyStepFailedMakesCaseFailed()` → tests AC from US 3.2

2. **Test Structure: Given-When-Then**
   ```java
   @Test
   void testMarkStepAsPassed() {
       // Given: a test run with steps
       // When: marking step as PASSED
       // Then: status should be PASSED and case status should be updated
   }
   ```

3. **Mock Dependencies**
   - Use existing mocks from TestRunServiceTest
   - Don't create new dependencies

4. **Assertions Match AC**
   - Each assertion verifies one AC point
   - Add comments explaining what AC is being verified
